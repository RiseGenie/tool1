Comment Copilot for LinkedIn

Settings are stored only in your browser and are sent only to Anthropic's API when you click "Draft comment."

Claude API key

Comment Copilot uses your own Anthropic API key — there's no shared backend. Get one at console.anthropic.com.

Model

Sonnet is fast and inexpensive for short comment drafts. Switch to Opus if you want more nuanced drafts and don't mind the extra cost.

About you (optional)

A short bio so drafts sound like you, not a generic commenter. It's included in every request as context — never claimed as a quote from you.

Your niche (optional)

Comma-separated topics or keywords. As you scroll your own feed, posts that mention one of these get a small "In your niche" badge so they're easy to spot. This only highlights posts you're already seeing — it never searches or scrapes LinkedIn on its own, and it never likes or comments for you.
